# Migrate from 0.32.x to 0.40.0-beta.1

`0.40.0-beta.1` is the first Core Reset prerelease. It deliberately replaces the broad 0.32.x product surface instead of preserving compatibility aliases.

## Upgrade

```bash
npm install -g @lubab/madar@next
cd /path/to/repository
madar generate . --update
madar install claude
# or: madar install codex
```

Restart or reconnect the client after installation. Existing 0.32.x releases remain available by exact npm version if a removed surface is still required.

## Supported surface

The CLI now exposes only:

```text
madar generate [path] [options]
madar query "<question>" [--graph graph.json] [--budget tokens]
madar status [graph.json]
madar doctor [graph.json]
madar install <claude|codex> [--uninstall]
madar mcp
```

The MCP server advertises only the tools capability and one `retrieve(question, budget?)` tool. It exposes no resources or prompts.

## Command migration

| 0.32.x surface | 0.40.0-beta.1 |
| --- | --- |
| `madar watch .` | `madar generate . --watch` |
| `madar serve --stdio --auto-refresh` | `madar mcp` |
| `madar claude install` | `madar install claude` |
| `madar codex install` | `madar install codex` |
| `madar claude uninstall` | `madar install claude --uninstall` |
| `madar codex uninstall` | `madar install codex --uninstall` |
| implicit `madar .` | `madar generate .` |

The following command names have no 0.40 compatibility alias: `bench:suite`, `benchmark`, `compare`, `diff`, `eval`, `explain`, `federate`, `handoff`, `hook`, `pack`, `path`, `prompt`, `proof-report`, `review-compare`, `save-result`, `summary`, `telemetry`, `time-travel`, and `try`.

The old client-named commands are also removed: `aider`, `claw`, `copilot`, `cursor`, `droid`, `gemini`, `opencode`, `trae`, and `trae-cn`. Only Claude Code and Codex have supported installers. Other MCP hosts can register command `madar`, arguments `["mcp"]`, stdio transport, and the repository as the working directory.

Removed flags include `--legacy`, `--spi`, `--include-docs`, `--docs`, `--wiki`, `--stdio`, `--mcp`, `--auto-refresh`, and every `--neo4j-*` option. There is no Neo4j export route.

## MCP tool migration

`retrieve` is the only surviving MCP tool, with required `question`, optional positive-integer `budget`, and no additional input properties.

These 0.32.x tools are retired: `query_graph`, `get_node`, `graph_diff`, `semantic_anomalies`, `get_neighbors`, `shortest_path`, `explain_node`, `graph_stats`, `graph_summary`, `god_nodes`, `get_community`, `community_details`, `community_overview`, `impact`, `call_chain`, `pr_impact`, `context_pack`, `context_pack_session_reset`, `context_expand`, `context_prompt`, `context_session_reset`, `relevant_files`, `feature_map`, `risk_map`, `implementation_checklist`, and `time_travel_compare`.

Tool profiles and `MADAR_TOOL_PROFILE` are removed. There is no strict/core/full mode or fallback MCP surface.

## Language and file coverage

The canonical index supports `.js`, `.jsx`, `.ts`, and `.tsx`.

The following former code-extraction extensions are no longer indexed: `.py`, `.rb`, `.go`, `.java`, `.rs`, `.c`, `.cc`, `.cpp`, `.cxx`, `.h`, `.hpp`, `.kt`, `.kts`, `.cs`, `.scala`, `.php`, `.swift`, `.zig`, `.lua`, `.ex`, `.exs`, `.jl`, `.ps1`, `.m`, `.mm`, and `.toc`.

Document and binary extraction is also removed. This includes `.md`, `.txt`, `.rst`, `.pdf`, `.docx`, `.xlsx`, `.gif`, `.jpeg`, `.jpg`, `.png`, `.svg`, `.webp`, `.aac`, `.flac`, `.m4a`, `.mp3`, `.ogg`, `.opus`, `.wav`, `.avi`, `.m4v`, `.mkv`, `.mov`, `.mp4`, and `.webm`.

When a question depends on unsupported source, `retrieve` reports an explicit boundary rather than guessing.

## Graph and generated artifacts

Regenerate after upgrading. The 0.32.x graph and build-state formats are not loaded through a compatibility adapter.

`graph.json` is authoritative. `indexing-manifest.json` and `indexing-manifest.share-safe.json` are derived diagnostics only.

These former outputs are retired and are removed during a successful publication cleanup: `manifest.json`, `watcher-state.json`, `indexing-manifest.failed.json`, `indexing-manifest.failed.share-safe.json`, `cache/`, `docs/`, `wiki/`, `graph.html`, `graph-pages/`, `graph.svg`, `graph.graphml`, `cypher.txt`, `obsidian/`, and `GRAPH_REPORT.md`. The old `needs_update` and refresh-owner protocols are also retired.

## Client configuration migration

Fresh install, idempotent reinstall, and uninstall write no repository bytes. The installer may remove only exact, byte-recognized Madar-owned legacy content. Modified or user-owned content is left unchanged with a warning.

Recognized legacy surfaces include Madar-owned sections in `CLAUDE.md` and `AGENTS.md`; `.claude/madar-user-prompt-submit.cjs`; `.codex/madar-user-prompt-submit.cjs`; Madar entries in `.mcp.json`, `.claude/settings.json`, and `.codex/hooks.json`; the obsolete project-local `.codex/config.toml` block; Madar-owned `post-commit` and `post-checkout` hook spans; and generated Madar skills under `.claude/skills/` or `.agents/skills/`.

Claude Code now receives supported per-project local MCP registration outside the repository. Codex receives one workspace-hashed block in `$CODEX_HOME/config.toml` or `~/.codex/config.toml` with command `madar`, arguments `["mcp"]`, the exact workspace `cwd`, `startup_timeout_sec = 180`, and `tool_timeout_sec = 60`.

## Validation boundary

Core Reset has machine-tested graph, index, retrieval, packaging, startup, and client-transport gates. The planned Native-versus-Graphify-versus-Madar provider campaign did not run, so this beta makes no comparative token, latency, cost, correctness, natural-activation, or retention claim.
